GitHub に接続

データ置き場（リポジトリ exercise-log）とつなぐため、 専用のアクセストークンを1回だけ入力します。トークンはこの端末のブラウザ内にだけ保存され、 コードやリポジトリには含まれません。

トークンの作り方

  1. GitHub にログイン → 右上のアイコン → Settings
  2. 左下の Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access で Only select repositories を選び、exercise-log だけを指定
  4. Permissions → Repository permissions → Contents を Read and write に設定
  5. 発行されたトークンを、上の欄に貼り付けて「接続」

※ Webコミック管理で使っているトークンは、リポジトリを webcomic だけに 絞って発行した場合は exercise-log には使えません。その場合は上の手順で exercise-log 用に新しく発行してください（発行時に両方のリポジトリを選ぶこともできます）。
